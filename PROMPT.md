# PROMPT – Practice 1 implementation brief

This repository implements practice 1 of subject 21724, Aplicacions Distribuïdes a Internet i Interfícies d'Usuari (ADIU), Universitat de les Illes Balears. The practice covers Tema 1 of the syllabus: the web application design and development paradigm with its data model, presentation and control.

The Syllabus can befound at syllabus.txt.

The official assignment is in assignment.md. This document is the implementation brief for the chosen project.

Implement the application described in APP.md

##  Hard constraints

- Backend: PHP + MySQL on XAMPP (Apache + MySQL). No frameworks of any kind.
- The backend follows an MVC pattern, but kept as small as possible.
- All code must be really minimalist and simple, easy to understand, with no sophisticated constructions.
- Frontend: no frameworks. Vanilla CSS with flexbox, semantic HTML.
- JavaScript: vanilla only. Data is requested with the Fetch API.
- Charts: Highcharts, and Highmaps for the map. Nothing else.
- The website UI is written in Catalan. Code identifiers and documentation are in English.
- The UI is black and white only (grayscale) and as accessible as possible: high contrast, semantic HTML, descriptive headings, labeled forms, keyboard friendly.
- Charts may use black and gray tones so the two series stay distinguishable without breaking the black and white rule.
- Code comments must avoid dashes and semicolons so they read like natural human writing and do not look AI generated.
